# Contributing

This repository is only the profile page you see on github.com/ClaySecAI. There is no code here.

- A typo or a broken link on the page: a pull request is welcome.
- Anything about one of the projects it links to: open the issue or pull request in that project's
  own repository, where its tests and its contributing guide live.

Please keep your own personal details, and anyone else's, out of issues and pull requests.

Security problems are reported privately; see [SECURITY.md](SECURITY.md). Everyone taking part
follows the [code of conduct](CODE_OF_CONDUCT.md).
